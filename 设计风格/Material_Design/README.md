# Material Design 设计方案与演示主题

设计方案和配套主题在本目录成套维护。

| 文件 | 用途 |
|---|---|
| [Material_Design_设计方案.md](Material_Design_设计方案.md) | 色彩、排版、空间、组件、交互、动效与交付规范 |
| [Material_Design_演示主题.css](Material_Design_演示主题.css) | 与方案配套的主题角色和组件样式，使用 `.material-tech` 作用域 |

修改规范中的主题值时，同步更新配套 CSS；主页使用的 [主题部署副本](../../docs/assets/material-theme.css) 也需同步并检查一致性。

可复用视觉素材分别保存在 [Logo](../素材/Logo/README.md)、[交互球体](../素材/交互球体/README.md) 和 [托举人物](../素材/托举人物/README.md) 目录。主页的已确认取舍见 [网页设计经验与偏好](../用户习惯/网页设计经验与偏好.md)。
