# 网页设计经验与偏好

更新于 2026-10-09。以下是个人宇宙主页迭代确认的方向，后续以用户最新反馈为准。

## 已确认的设计偏好

- **有氛围的动态背景。** 保留深色星空、缓慢星云与星粒运动；默认播放，允许暂停，并尊重系统减少动态设置。
- **主页聚焦球体探索。** 栏目从球体进入；去掉顶部栏目导航和“走进我的世界”按钮。左上角保留莲子心 Logo，右上角保留动效与 GitHub 控件。
- **同一背景中的内容窗口。** 关于我、博客、兴趣和经历在星空上展开，栏目间滑动切换，背景持续播放；每个栏目有独立链接。
- **导航只放一处。** 栏目导航保留在窗口内，去掉底部翻页栏；左右方向键切换、Esc 退出，手机支持横向滑动。
- **紧凑且清楚。** 导航和控件不占据大块首屏空间；正文保持清晰、可滚动，窄屏布局自然重排。
- **品牌长期保留。** Logo 与导航分开控制；品牌图形、球体、人物素材和经验集中保存，供其他项目复用。

## 设计取舍

| 场景 | 采用的做法 |
|---|---|
| 主页探索 | 让球体承担栏目入口；Logo 表达品牌，GitHub 与动效控件承担独立功能。 |
| 打开内容 | 在原有星空上展开窗口，关闭后回到原场景，保持探索的连续感。 |
| 阅读正文 | 窗口内使用稳定、对比清楚的内容表面；星空在窗口周围可见，装饰不干扰阅读。 |
| 切换栏目 | 保留一组窗口导航，使用短暂滑动过渡；键盘与触摸提供同等入口。 |

## 可复用的实现经验

- 星空、人物、球体和内容窗口分别分层。关闭窗口后恢复主页，并把键盘焦点交还球体。
- 区分背景与球体的动画状态：开窗后星空继续、球体暂停；标签页隐藏时停止绘制。缓存星云纹理，低性能设备降低细节、像素比和帧率。
- 内容窗口限制在视口内，只让内容区域滚动；支持独立链接、浏览器前进后退、栏目滚动位置保留及快速切换时取消旧动画。
- 全局方向键避开文字输入与已有键盘控件，保留兴趣列表、时间轴自身的操作。
- 素材源文件保存在设计目录，网页使用部署副本；修改后通过同步脚本更新并检查一致性。

## 这次迭代的具体教训

- **动效消失要同时查绘制与默认状态。** 恢复动画算法后，还要确认首页默认开启、初始化正确；性能优化优先采用缓存与按状态暂停。
- **隐藏导航不要连带隐藏品牌。** Logo 曾随整个页头一起消失；品牌、栏目导航和辅助控件应分别布局与控制可见性。
- **窗口定位不等于高度受限。** 仅设置顶部和底部位置时，内容仍可能撑出视口；明确限制窗口高度，并让内容区域承担滚动。
- **关闭窗口要恢复可操作的焦点。** 已收起的球体导航链接不能作为返回目标，关闭后应聚焦球体按钮。
- **视觉素材应能独立调整。** 人物保留透明背景和空白手心，球体单独绘制；先确认不规则孔洞、暗骨架、透光膜与内核的层次，再添加运动。

## 协作习惯

- 先看实际预览，再根据具体位置的反馈逐步调整；已明确的方向直接落实。
- 交付可复用源文件、简短说明和验证结果；完成改动后保存 Git 提交。
- 检查桌面与手机、键盘、减少动态、关闭返回和资源加载；只报告实际验证过的结果。
- 接到新反馈时更新同一份实现与说明，保留已经确认的取舍；Git 提交只包含本次改动，保留其他正在进行的工作。

## 复用范围

球体入口与内容窗口是当前个人主页的选择。用于长文、资料手册或其他网站时，应重新判断阅读方式；品牌素材、分层方法、键盘规则和验证流程可分别复用。
