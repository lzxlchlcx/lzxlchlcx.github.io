# 设计风格目录

这里保存网页设计规范、已确认的用户偏好，以及可单独复用的视觉素材。规范和主题样式放在本目录，素材文件及其同步脚本归入各自的素材文件夹。

## 内容入口

| 内容 | 位置与用途 |
|---|---|
| [设计规范](Material_Design_设计方案.md) | 色彩、排版、间距、组件、交互和动效规则 |
| [主题样式](Material_Design_演示主题.css) | 与设计规范配套的颜色和组件样式 |
| [用户习惯](用户习惯/网页设计经验与偏好.md) | 主页迭代确认的偏好、取舍和复用边界 |
| [Logo 素材](素材/Logo/README.md) | 莲子心 Logo、不同背景版本、网站图标及同步脚本 |
| [交互球体](素材/交互球体/README.md) | 球体渲染器、独立预览、设计经验及同步脚本 |
| [托举人物](素材/托举人物/README.md) | 人物原图、网页优化图、编辑提示词及同步脚本 |

## 素材保存规则

每种素材单独保存到 `素材/<素材名称>/`。源文件、优化版本、提示词或生成参数、相关设计经验和 `README.md` 按素材类型归档；同步脚本也放在对应素材文件夹内。

球体与人物分别保存。球体提供 [独立预览](素材/交互球体/preview.html)，用于检查外观和运动；人物只保留图片与提示词。

素材自身的经验随素材保存，跨素材的设计经验与用户偏好放在 `用户习惯/`。移动目录后，更新相关文档链接、同步脚本路径和预览入口。

## 修改与同步

`设计风格/素材/` 保存编辑源，网页引用 `docs/assets/` 中的部署副本。修改源文件后，在仓库根目录运行对应脚本：

```sh
python3 设计风格/素材/Logo/sync_brand_assets.py
python3 设计风格/素材/交互球体/sync_assets.py
python3 设计风格/素材/托举人物/sync_assets.py
```

在命令末尾加 `--check` 可检查源文件与部署副本是否一致，不修改文件。各脚本只管理自己的素材。

Logo 脚本将默认 Logo 和 favicon 同步到 `docs/assets/brand/`；球体与人物脚本分别将渲染器和人物图片同步到 `docs/assets/`。具体文件映射见各素材目录的说明。

提交前检查同步结果、文档链接、脚本语法及实际可用的预览，只报告已完成的验证。
