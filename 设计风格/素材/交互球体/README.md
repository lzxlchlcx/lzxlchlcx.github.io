# 交互球体素材

球体渲染器、设计经验和独立预览集中保存在此目录，可单独复制用于后续项目。球体由程序绘制，人物图片单独保存在 [托举人物目录](../托举人物/README.md)。

## 文件与用途

| 文件 | 用途 |
|---|---|
| [orb.js](orb.js) | 独立 Canvas 球体渲染器，提供动画启停、减少动态和尺寸更新接口 |
| [preview.html](preview.html) | 单独预览球体的孔洞、骨架、透光膜和动效 |
| [交互球体设计经验.md](交互球体设计经验.md) | 几何、材质、运动、复用流程和排查顺序 |
| [sync_assets.py](sync_assets.py) | 将渲染器同步到主页部署目录 |

## 查看与复用

用浏览器打开 `preview.html` 即可预览，无需启动服务或安装依赖。预览默认显示静帧；按“播放动效”观察运动，系统减少动态时保持静态。

在其他项目使用时，复制 `orb.js`，在 Canvas 元素上调用 `window.createOrb()`。渲染器没有第三方脚本依赖；预览页提供一份可直接参考的画布尺寸和动效控制实现。

## 同步主页渲染器

本目录是球体渲染器的编辑入口，主页引用的部署副本位于 `docs/assets/orb.js`。修改后，在仓库根目录执行：

```sh
python3 设计风格/素材/交互球体/sync_assets.py
python3 设计风格/素材/交互球体/sync_assets.py --check
```

同步范围仅为 `orb.js`；`--check` 只检查源文件与部署副本是否一致。同步脚本用于本仓库目录布局。
