## 交互与动画

- `orb.js`：独立 Canvas 球体；94 个大小不同的弧形孔洞、深色金属骨架、彩色透光膜、尖刺与边缘光。非匀速多轴旋转、扭曲、起伏及收缩；低性能设备使用 70 个孔洞。
- `atmosphere.js`：首屏动态星空，恢复分层星粒闪烁与漂移、缓存星云、缓慢极光、漂浮星尘和偶发流星；星云纹理仅在初始化时生成并缓存，Canvas 尺寸跟随首屏实际大小。
- `home.js`：球体导航、同一星空上的独立内容窗口、栏目滑动切换、兴趣切图与时间轴详情。`#about`、`#blog`、`#interests`、`#journey` 可独立访问，支持浏览器前进 / 后退，每个栏目保留窗口内滚动位置。
- `home.css`：主页阅读布局与组件。`--orb-size`、`--orb-y` 控制球体；`.figure-layer` 控制人物位置。
- 主页左上角保留莲子心 Logo，通过球体打开同页内容窗口，右上角保留动效与 GitHub 控件；栏目导航只放在窗口内。窗口内滚动阅读，通过栏目导航、左右方向键或横向触摸滑动切换栏目；关闭按钮、Esc 或点击窗口外回到首页。没有底部翻页栏；方向键优先保留兴趣列表、时间轴等控件自身的操作。快速切换会取消前一次动画。无 JavaScript 时保留原始连续页面。
- 兴趣列表悬停、键盘聚焦或方向键切换配图；点击列表或当前配图跳转。手机提供独立切图按钮。
- 横向时间轴悬停、聚焦或点击时间点，在下方显示详情；左右键 / Home / End 切换，Esc 收起。详情参与正常排版，字体放大时可以增长，内部链接可以点击。
- 右上角“关闭动效 / 开启动效”控制首屏持续动画，默认开启；内容窗口打开后星空继续播放，球体暂停；隐藏页面时停止 Canvas 绘制。系统减少动态时禁用持续动效与窗口切换动画。
- 低性能设备与触摸设备降低星粒数量、像素比和帧率。移除了指针视差及其全局样式更新。

## 设计主题

- 依据仓库 `设计风格/Material_Design_设计方案.md` 2.0.0 的网页阅读规则修订：深蓝 `#0F172A`、紫蓝强调色、不透明语义表面、系统无衬线字体、18px 正文和至少 16px 的辅助文字。
- `material-theme.css` 是配套 `Material_Design_演示主题.css` 的部署副本，保留原始版本说明和颜色、间距、圆角、动效角色。参考文件更新后同步此副本；主页组件引用共享角色，不直接链接部署目录之外的文件。
- 主要内容卡片使用 24px 圆角，小卡片 16px，导航与按钮使用胶囊形状；操作区域至少 48px，保留独立键盘焦点轮廓。
- 手机重排为单列，时间轴详情保持文档流；锚点偏移跟随导航栏真实高度，支持文字放大。
- 本次沿用深色主题和原有内容插画；没有新增浅色主题切换或演示控制器。
